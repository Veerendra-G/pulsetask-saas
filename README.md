# 🚀 PulseTask — Enterprise React SaaS Task Management Platform

A high-performance, modern SaaS task management web application built with **React**, **Tailwind CSS**, and **Lucide Icons** — inspired by Linear, Notion, and Asana.

---

## 🌟 SaaS Features

- **Multi-View System**:
  - 📋 **List View**: Dense, high-information table with quick checkmarks, project pills, priority badges, and date alerts.
  - 🗂️ **Kanban Board**: Drag-and-drop workflow across *Backlog / To Do*, *In Progress*, *In Review*, and *Completed* stages.
  - 📊 **Analytics Dashboard**: Real-time KPI counters, team velocity metrics, task distribution charts, and overdue tracking.
- **Enterprise Navigation**:
  - Collapsible responsive sidebar with workspace switcher (*Acme Global / Pro*).
  - Quick filters: *Due Today*, *Upcoming*, *Completed*, *All Tasks*.
  - Project groupings: *Engineering, Design, Marketing, Security, Executive*.
- **Real-Time Search & Sorting**:
  - Instant fuzzy search across titles, descriptions, and tags.
  - Multi-criteria sorting: Due Date, Priority (Urgent/High/Medium/Low), Alphabetical, or Created Date.
- **Micro-Interactions**:
  - Confetti celebration burst upon task completion (`canvas-confetti`).
  - Toast notification system with 5-second undo support.
  - Responsive dark & light themes with persistence.
- **Offline & Cloud Ready**:
  - Instant `localStorage` auto-saving.
  - One-click JSON backup export.
